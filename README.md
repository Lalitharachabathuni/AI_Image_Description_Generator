# AI Image Description & Alt-Text Generator

This project uses Google's Gemini Vision model to generate image descriptions automatically.

## Features

* Upload up to 5 images
* Generate Alt Text
* Generate Detailed Description
* Generate SEO Caption
* Export results to CSV
* Streamlit web interface

## Technologies Used

* Python
* Streamlit
* Google Gemini API
* Pandas
* Pillow

## How to Run

1. Install dependencies
2. Add your Gemini API Key
3. Run:

streamlit run app.py
